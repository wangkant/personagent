## 聊天平台和你的帳號

personagent 有兩種方式接入聊天平台。QQ 官方機器人、個人微信、Telegram、Discord、Matrix、Twitch、IRC、Zulip、VK 和 Stoat 這十個平台由它直接連線；其他平台透過第三方橋接程式接入，通常是 personagent 代為下載並執行的 AstrBot。風險高低取決於連線時以何種身分登入。

- **官方機器人介面**原本即為機器人而設計，包括 QQ 官方機器人介面、騰訊為個人微信提供的 iLink 機器人介面、Telegram 和 Discord 的機器人介面、Zulip 的通用機器人（Generic bot）、VK 社群的 Bots Long Poll API（使用社群存取金鑰）、Stoat 的機器人，以及 Slack、KOOK、飛書、釘釘、企業微信等平台的介面。使用時仍須遵守各平台的開發者條款和頻率限制。
- **開放網路上的獨立帳號。** 在 Matrix、Twitch 和 IRC 上，機器人是你為其另外建立的一般帳號，personagent 使用該網路公開文件中的介面：在機器人帳號所在的伺服器上使用 Matrix Client-Server API；使用 Twitch API，並由角色的帳號為你註冊的開發者應用程式核准登入；使用透過 TLS 連線的 IRC 協定及機器人自己的暱稱。該伺服器、Twitch 和各 IRC 網路的條款均適用，各聊天室和頻道的規則同樣適用。部分網路要求機器人加入前須取得許可，例如 Libera.Chat 規定，AI 機器人加入頻道前須取得該頻道管理員的明確許可。
- **非官方用戶端**以一般使用者帳號登入，再由軟體代為操作。平台不認可此種做法，條款中可能明令禁止，帳號可能因此遭到限制、凍結乃至永久停權。這類方式包括：
  - **透過 NapCat、LLOneBot、Lagrange 或其他 OneBot 實作接入 QQ**，即進階選項中的 OneBot v11。使用 QQ 官方機器人則完全不需要它們。騰訊不認可這些實作，從雲端伺服器或境外 IP 登入時風險最高。
  - **透過 mautrix 橋接接入 WhatsApp、Signal、Messenger、Instagram、Google Messages 等**，即 Matrix 聯結器的接入方式。橋接程式是這些網路的非官方用戶端，其中部分網路的條款對自動傳送訊息另有規定。詳見 [Matrix 聯結器的說明](../integrations/matrix/README.zh-TW.md#各網路的條款)。
  - 其他任何以真人帳號登入的方式。

如果使用其中任何一種，請準備一個**專用且遺失亦無妨的次要帳號**，不要使用主要帳號；條件允許時，請在家用網路中執行，不要部署在雲端伺服器上。接入每個網路之前，請詳閱其現行條款。personagent 的作者，以及與它搭配使用的第三方專案（AstrBot、NapCat、Koishi、mautrix 等）的維護者，均不對帳號遺失或受限承擔責任。

## 告知他人這是機器人

- 告知聊天中的成員，他們正在與 AI 對話；將它加入群組之前，請先徵得群主或群組管理員同意。帳號名稱應讓人一看即知是機器人；平台支援個人簡介時，也請在簡介中註明。
- 當有人認真詢問它是否為 AI 時，personagent 的設計是如實回答。請勿透過修改人設讓它否認。
- 請勿以它冒充真人，也不要讓任何人誤以為自己正在與真人交談。部分平台和國家要求標明機器人身分，或對自動化帳號有所限制，請查明適用於你的規定。
- 請勿將它加入回覆可能造成傷害或誤導的群組，例如討論醫療、法律、投資或心理危機的群組，以及有未成年人的群組。
- 有人要求它離開，或詢問它記錄了自己的哪些資訊時，請認真處理。管理員可以讓它刪除某項記錄（`<名字> 忘掉 ...`），它儲存的所有內容都位於其資料夾中（見下文）。

## 模型服務商可見的內容

每次回覆時，模型服務商都會收到一段提示詞，其中包括人設、聊天中最近的訊息（含暱稱）、機器人為該聊天記下的筆記，以及它從已學內容中檢索出的部分。如果設定了視覺模型，圖片會傳送給該模型。你啟用的其他服務也會看到其中一部分，包括你設定的備用模型、判斷模型、自評模型和向量模型，以及網路搜尋。網路搜尋會將一小段查詢傳送給 Tavily（填寫了金鑰時）或 DuckDuckGo。更新檢查每天最多一次，只向 pypi.org 傳送 personagent 的版本號；設定 `UPDATE_CHECK_ENABLED=false` 可以關閉。

使用前請閱讀每家服務商的資料保留政策。部分服務商會儲存提示詞，部分會將其用於訓練，除非你主動選擇不參與。預設的 OpenRouter 免費模型可能用到這類服務商。本機模型（Ollama、llama.cpp）的提示詞只留在你自己的電腦上。聊天中的其他人並未同意任何服務商的條款，請告知他們訊息會傳送至何處。

## 儲存於你電腦上的內容

它儲存的所有內容都位於 personagent 資料夾中。設定和 API 金鑰位於 `.env` 中，機器人憑證和代為執行的 AstrBot 位於 `platforms/` 中，`runtime/` 中則有聊天筆記、它判斷過的反應（原文照錄）、學習紀錄和學到的範例。如果設定了 `SERVER_LOG_FILE`，記錄檔中也可能包含對話細節。請妥善保管此資料夾，不要公開，也不要附加在 issue 中；如果在意它學到的內容，請做好備份。各國關於儲存和處理他人訊息的法律不盡相同，遵守所在地的法律是你自己的責任。

它可能學到錯誤的內容。一項改變需要同一聊天中兩次一致的反應，其中至少一次來自被回覆者。每項改變都記錄在僅可追加的學習紀錄中，你可以透過 `personagent learned` 或本機頁面的「動態」檢視及復原。請定期檢查。
