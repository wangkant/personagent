# personagent を使い始める

[English](start.md) · [简体中文](start.zh-CN.md) · [繁體中文](start.zh-TW.md) · 日本語 · [한국어](start.ko.md) · [Español](start.es.md) · [Français](start.fr.md) · [Deutsch](start.de.md) · [Português (Brasil)](start.pt-BR.md) · [Русский](start.ru.md) · [ガイド全文](guide.ja.md)

## 開く

PyPI から personagent をインストールして開きます。

```sh
python -m pip install personagent
personagent
```

[uv](https://docs.astral.sh/uv/) があれば、`uvx personagent` で別途インストールせずに実行できます。

Windows では、ページは専用のウィンドウで開きます。macOS と Linux ではブラウザーで開きます。`pip install "personagent[app]"` を入れると、そちらでもウィンドウで開けます。

コーディングアシスタントにセットアップを任せることもできます。[setup-for-agents.md](setup-for-agents.md) を読んで personagent をセットアップするよう頼んでください。

Windows では、ソースの ZIP をダウンロードして展開し、`start.bat` をダブルクリックする方法もあります。フォルダー内に専用の Python 環境を作り、同じページを開きます。初回は、デスクトップとスタートメニューに personagent のアイコンも置きます。

クローンから実行する場合は、専用の venv を用意します。`python -m venv .venv` のあと、`.venv/bin/python -m pip install -e .` と `.venv/bin/python -m persona_agent` を実行します。Windows のインタープリターは `.venv\Scripts\python.exe` です。`start.bat` をダブルクリックしてもかまいません。

## キーを入れてチャットする

モデルサービスを選び、API キーを貼り付けて **確認してチャットを開始** をクリックします。最初は OpenRouter の無料モデルと「温かな聞き手」のキャラクターが選ばれています。キーは無料で、上限は 1 日 50 リクエストです。**詳細設定** にはモデル名と API アドレスが、**名前または性格を選択** にはキャラクターの名前と性格があります。

キーはあなたのコンピューターの中に留まります。確認するには **表示** をクリックします。チャットのメッセージは選んだモデルサービスに送られ、そのサービスの通常料金がかかります。

キャラクターはページの中で返信し、スタンプや画像を送った場合はそれもページに表示されます。キャラクターが後から送るメッセージ（自分から始めるメッセージなど）は、数秒以内にチャットに表示されます。設定は保存されるので、次回からはすぐチャットに入れます。

セットアップが済むと、**キャラクターと設定** に **ペルソナ** 欄が現れ、キャラクターの元になる文章が入っています。キャラクターの人物像や話し方を書き直して **ペルソナを保存** をクリックします。変更はすぐに反映され、キャラクターが学んだことは残ります。

その下の **その他の機能** で、ウェブ検索、画像の理解、自分から話しかける機能をオンにできます。検索は標準で DuckDuckGo を使います。Tavily のキーがあれば、より安定します。その下の **詳細設定** には、これまで `.env` でしか変更できなかった設定がまとめられています。プラットフォームを連携するまで、**チャット** ビューには短い **はじめに** バーが表示されます。

プラットフォームを連携しなくても使えるビューが、ほかに 2 つあります。**練習** はスクリプト化されたデモを再生し、練習用のグループチャットを実行します。そこでは、キャラクターが返信する理由や黙る理由を確認できます。**アプリ** はキャラクターが依存するすべてのサービスを確認し、ログを表示するほか、更新、バックアップ、デスクトップアイコンを扱います。

## ほかのプラットフォームに参加させる

1. **プラットフォーム連携** をクリックしてプラットフォームを選びます。連携すると、キャラクターはそのプラットフォームのグループチャットと DM に返信します。
   - **スキャンで連携**：QQ と個人の WeChat。**QR コードを取得** をクリックし、スマートフォンで確認します。
     - QQ：モバイル版 QQ でスキャンします。QQ がボットを作成するか、手持ちのボットを選べるようにし、personagent がそのキーを取得します。[QQ のボットページ](https://q.qq.com/qqbot/openclaw/login.html)で自分でボットを作った場合は、**値の貼り付けで連携** をクリックして AppID と AppSecret を入力します。
     - WeChat：WeChat でスキャンします。WeChat はこの種のボットにグループメッセージを渡さないため、ボットは 1 対 1 のチャットのみです。
   - **1〜2 個の値を貼り付け**：Telegram（@BotFather のトークン）、Discord（ボットトークン。Message Content Intent をオンにしておきます）、KOOK、Feishu、DingTalk、Slack、WeCom AI ボット、Mattermost、Misskey、Matrix、Twitch、IRC、Zulip、VK、Stoat。どの値をプラットフォームのコンソールからコピーするかは、ページに表示されます。それ以外は既定値を使います。Twitch では、リンクからサインインを承認する操作も必要です。
   - **上級**：WeCom アプリ、WeChat 公式アカウント、QQ の Webhook には、コールバックポートに転送する公開アドレスが必要です。OneBot v11（NapCat）と Satori には、このコンピューターで動く別のソフトウェアが必要です。
2. personagent は QQ、WeChat、Telegram、Discord、Matrix、Twitch、IRC、Zulip、VK、Stoat に自分で接続します。ほかのプラットフォームはサードパーティのブリッジである AstrBot を経由します。そのいずれかを初めてつなぐとき、personagent は AstrBot と別の Python 3.12 ランタイムをダウンロードするので、終わるまでページを開いたままにしてください。その後 AstrBot はバックグラウンドで動き、ログインするダッシュボードはありません。
3. personagent は保存する前に、認証情報をプラットフォームに確認します。プラットフォームに拒否された場合はページに表示され、何も保存されません。
4. 連携中のプラットフォームは **プラットフォーム連携** の上部に一覧で表示され、そこから設定し直したり連携を解除したりできます。
5. ページを使わない場合（たとえばディスプレイのないサーバー）は、ターミナルで `personagent connect <platform>` を実行すると、QQ、WeChat、Telegram、Discord、Matrix、Twitch、IRC、Zulip、VK、Stoat を同じ手順と確認で接続できます。`personagent connect` だけを実行すると、これらが一覧表示されます。このコマンドは[ガイド全文](guide.ja.md#ターミナルでプラットフォームを接続する)で説明しています。

QQ ボットを探すには、モバイル版 QQ で「連絡先 → ボット」を開きます。個別にチャットするか、自分が所有するグループに追加します。この方法は QQ 公式のボットプラットフォームを使うので、個人の QQ アカウントも追加のソフトウェアも要りません。ボットの行き先は QQ が決めます。ボットが認証されるまでは管理者が所有するグループにしか入れず、用意するサンドボックスはありません。グループのオーナーがそのグループのボットのプロフィールですべてのメッセージの受信をオンにしない限り、グループでは自分を @ したメッセージだけが見えます。認証などアカウント側のことは [QQ のボットガイド](https://bot.q.qq.com/wiki/bot_new_product-intro/)に書かれています。

QR コードの期限が切れたら、新しいものを取得してください。ダウンロードに失敗したら、モデルの設定をやり直さずに再試行できます。プラットフォームを連携しても、キャラクターに開放されるのはそのプラットフォームのグループと DM だけです。ほかのアダプターの許可リストはそのままです。LINE は提供していません。AstrBot が LINE のコールバックを受け取れるのはダッシュボード経由だけで、personagent はダッシュボードを動かさないためです。

## 次回

personagent をもう一度開きます。設定は保持されており、連携中のプラットフォームは自動的に再開します。すでに動いていれば、開き直すとそのウィンドウが前面に戻ります。使っている間は開いたままにしてください。**終了** をクリックしてもウィンドウを閉じても、起動したプロセスは一緒に止まります。クラッシュで残ったものは次の起動時に止められます。Windows では、`personagent shortcut` でデスクトップとスタートメニューにアイコンを置けます。そこからならターミナルなしで開けます。同じく Windows では、アプリビューの **バックグラウンドで実行** を使うと、ウィンドウを閉じても personagent が通知領域のアイコンの状態で動き続け、キャラクターは応答を続けます。

PyPI に新しいバージョンが出ると、**チャット** ビューにリリースノートへのリンクと、このコピーのインストール方法に合った更新コマンドが表示されます。ソースの ZIP から展開したコピーには、代わりにリリースページから新しいソースをダウンロードするリンクが出ます。ほとんどのインストールでは、アプリビューの **更新して再起動** で更新をインストールできます。personagent が pypi.org に問い合わせるのは多くても 1 日 1 回で、リクエストに含まれるのはバージョン番号だけです。確認をオフにするには、`.env` に `UPDATE_CHECK_ENABLED=false` と設定します。

コマンドラインを使用する場合は、`personagent start --terminal`、`personagent init --terminal`、`personagent up`、または `chat`、`demo`（キー不要）、`run`、`connect` の各コマンドを使ってください。既存の `.env`、編集したペルソナ、学習した記憶は保たれます。ほかのプラットフォームについては[ガイド全文](guide.ja.md)を参照してください。
