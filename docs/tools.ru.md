# Скрипты в `tools/`

[English](tools.md) · [简体中文](tools.zh-CN.md) · [繁體中文](tools.zh-TW.md) · [日本語](tools.ja.md) · [한국어](tools.ko.md) · [Español](tools.es.md) · [Français](tools.fr.md) · [Deutsch](tools.de.md) · [Português (Brasil)](tools.pt-BR.md) · Русский

Скрипты в `tools/` предназначены для тех, кто запускает personagent из клона. Они не устанавливаются вместе с пакетом и читают `.env` и `runtime/` из клона. Запускайте их интерпретатором клона из корня репозитория:

```bash
.venv/bin/python tools/<script>.py --help     # Windows: .venv\Scripts\python.exe
```

Повседневные задачи решаются подкомандами `personagent`, а не скриптами: `personagent doctor`, `personagent learned` и `personagent eval`. Чтобы попробовать изменение промпта, используйте `personagent chat`. Чтобы измерить его, используйте `personagent eval`. `personagent eval --suite memory` работает без сети с ответами консолидации по сценарию, содержит 21 пример на язык и не требует ключа; в этой версии все они проходят. Остальные наборы вызывают модель.

| Скрипт | Что делает | Что нужно | Вызывает модель | Статус |
|---|---|---|---|---|
| `import_stickers_folder.py` | Импортирует папку изображений в библиотеку стикеров и размечает каждое, чтобы новая библиотека не начиналась пустой. `--dry-run` показывает количество, а `--no-tag` только копирует файлы | Папка изображений, а для разметки ещё `VISION_MODEL`, `VISION_API_KEY` и `VISION_BASE_URL` | Да, один вызов визуальной модели на изображение, если не указаны `--dry-run` или `--no-tag` | Поддерживается |
| `bootstrap_from_history.py` | Даёт новому развёртыванию разовый старт из истории группы QQ. Строит профиль стикеров и длины сообщений администратора и сохраняет увиденные стикеры в библиотеку | HTTP-сервер NapCat, стороннего клиента QQ, по адресу `QQ_ONEBOT_URL` (обязательно), и группы QQ в `ACCESS_GROUPS` или `--group` | Нет. Сохранённые стикеры позже размечает визуальная модель работающего бота | Экспериментальный, только QQ и NapCat |
| `sticker_holdout_eval.py` | Измеряет стабильность и точность фильтра одобрения стикеров на стикерах, размеченных вручную | `runtime/holdout.jsonl` (формат в `tools/holdout.example.jsonl`) и три настройки `VISION_*` | Да, изображения × `--runs` (по умолчанию 5) вызовов визуальной модели, около 150 для 30 изображений | Экспериментальный |
| `package_smoke.py` | Проверяет установленную команду `personagent` от начала до конца: версия, `init --no-input`, `chat`, `run` с `/health` и `doctor --json` | Установленный `personagent` (`--personagent PATH`) и больше ничего | Нет, отвечает сервер-заменитель | Поддерживается. CI запускает его на Linux и Windows |
| `welcome_smoke.py` | Проверяет установленную локальную страницу от начала до конца: `start --no-browser`, сохранение ключа, один чат с настоящим персонажем, второй запуск с повторным использованием страницы и чистый выход | Установленный `personagent` (`--personagent PATH`) и больше ничего | Нет, отвечает тот же сервер-заменитель | Поддерживается. CI запускает его на Linux и Windows |
| `window_smoke.py` | Открывает настоящее окно приложения на временной домашней папке, выполняет настройку страницы и общается в окне, затем закрывает его | В macOS и Linux — `personagent`, установленный с дополнением app (`pip install "personagent[app]"`); в Linux также дисплей, например `xvfb-run` | Нет, отвечает тот же сервер-заменитель | Поддерживается. CI запускает его на Linux, macOS и Windows |
| `release_notes.py` | Сверяет тег выпуска с `pyproject.toml` и выводит раздел CHANGELOG этой версии | Тег, например `v1.1.0` | Нет | Поддерживается. Его запускает процесс выпуска |
| `locale_gaps.py` | Считает для каждого языка в `persona_agent/locales/`, сколько фраз мастера настройки, чата в терминале и демо переведено. С кодом языка, например `ja`, выводит те, которых ещё нет и которые показывались бы по-английски | Ничего | Нет | Поддерживается. `tests/test_locales.py` завершается с ошибкой, если какой-либо фразы не хватает |

Экспериментальные скрипты — вспомогательные средства для исследований и сопровождения, они могут измениться или исчезнуть без периода устаревания. Скрипты, вызывающие модель, расходуют средства учётной записи из вашего `.env`; сначала прочитайте `--help` и попробуйте `--dry-run`, если он есть.
