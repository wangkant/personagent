# Скрипты в `tools/`

[English](tools.md) · [简体中文](tools.zh-CN.md) · [繁體中文](tools.zh-TW.md) · [日本語](tools.ja.md) · [한국어](tools.ko.md) · [Español](tools.es.md) · [Français](tools.fr.md) · [Deutsch](tools.de.md) · [Português (Brasil)](tools.pt-BR.md) · Русский

Скрипты в `tools/` предназначены для тех, кто запускает personagent из клона. Они не устанавливаются вместе с пакетом и читают `.env` и `runtime/` из клона. Запускайте их интерпретатором клона из корня репозитория:

```bash
.venv/bin/python tools/<script>.py --help     # Windows: .venv\Scripts\python.exe
```

Повседневные задачи решаются подкомандами `personagent`, а не скриптами: `personagent doctor`, `personagent learned` и `personagent eval`. Чтобы попробовать изменение промпта, используйте `personagent chat`. Чтобы измерить его, используйте `personagent eval`.

| Скрипт | Что делает | Что нужно | Вызывает модель | Статус |
|---|---|---|---|---|
| `import_stickers_folder.py` | Импортирует папку изображений в библиотеку стикеров и размечает каждое, чтобы новая библиотека не начиналась пустой. `--dry-run` показывает количество, а `--no-tag` только копирует файлы | Папка изображений, а для разметки ещё `VISION_MODEL`, `VISION_API_KEY` и `VISION_BASE_URL` | Да, один вызов зрения на изображение, если не указаны `--dry-run` или `--no-tag` | Поддерживается |
| `bootstrap_from_history.py` | Даёт новому развёртыванию разовый старт из истории группы QQ. Строит профиль стикеров и длины сообщений администратора и сохраняет увиденные стикеры в библиотеку | HTTP-сервер NapCat, стороннего клиента QQ, по адресу `QQ_ONEBOT_URL` (обязательно), и группы QQ в `ACCESS_GROUPS` или `--group` | Нет. Сохранённые стикеры позже размечает модель зрения работающего бота | Экспериментальный, только QQ и NapCat |
| `auto_reviewer.py` | Читает низкие самооценки из `runtime/eval.jsonl` и просит модель превратить каждую в пару «до и после». С `--apply` затем спрашивает вас по каждой паре, добавлять ли её в общий пул отзывов | `EVAL_ENABLED=true` в течение некоторого времени, чтобы появились оценки | Да, один вызов на проверенную запись (`--limit`, по умолчанию 20). `--dry-run` ничего не вызывает | Экспериментальный. `--apply` пишет в пул, который используют все чаты. Чтобы одобрить исправление только для одного чата, используйте `personagent learned` |
| `evolution_benchmark.py` | Прогоняет настоящего агента по сценариям из `data/benchmark/` несколько раундов, один раз с включённым циклом самоулучшения и один раз с выключенным, и сравнивает их. `run` выполняет прогоны, `ingest` считывает оценки судьи | `LLM_API_KEY` и судья, который не является проверяемой моделью (`--judge export`, `openai` или `anthropic`, с `BENCH_JUDGE_MODEL`) | Да, очень много: каждый сценарий, раунд и вариант | Экспериментальный |
| `scenario_probe.py` | Пробует сценарии-кандидаты для бенчмарка на настоящей модели и сообщает, какие из них выявляют нужный бенчмарку сбой | `LLM_API_KEY`, файл сценариев-кандидатов в формате `data/benchmark/scenarios.train.en.jsonl` и `--judge-model` для прохода судьи | Да, ответ, самооценка и вызов судьи на сценарий | Экспериментальный, для создания бенчмарка |
| `sticker_holdout_eval.py` | Измеряет стабильность и точность фильтра одобрения стикеров на стикерах, размеченных вручную | `runtime/holdout.jsonl` (формат в `tools/holdout.example.jsonl`) и три настройки `VISION_*` | Да, изображения × `--runs` (по умолчанию 5) вызовов зрения, около 150 для 30 изображений | Экспериментальный |
| `package_smoke.py` | Проверяет установленную команду `personagent` от начала до конца: версия, `init --no-input`, `chat`, `run` с `/health` и `doctor --json` | Установленный `personagent` (`--personagent PATH`) и больше ничего | Нет, отвечает сервер-заменитель | Поддерживается. CI запускает его на Linux и Windows |
| `welcome_smoke.py` | Проверяет установленную локальную страницу от начала до конца: `start --no-browser`, сохранение ключа, один чат с настоящим персонажем, второй запуск с повторным использованием страницы и чистый выход | Установленный `personagent` (`--personagent PATH`) и больше ничего | Нет, отвечает тот же сервер-заменитель | Поддерживается. CI запускает его на Linux и Windows |
| `release_notes.py` | Сверяет тег выпуска с `pyproject.toml` и выводит раздел CHANGELOG этой версии | Тег, например `v1.1.0` | Нет | Поддерживается. Его запускает процесс выпуска |
| `locale_gaps.py` | Считает для каждого языка в `persona_agent/locales/`, сколько фраз мастера настройки, чата в терминале и демо переведено. С кодом языка, например `ja`, выводит те, которых ещё нет и которые показывались бы по-английски | Ничего | Нет | Поддерживается. `tests/test_locales.py` падает, если какой-то не хватает |

Экспериментальные скрипты — вспомогательные средства для исследований и сопровождения, они могут измениться или исчезнуть без периода устаревания. Скрипты, вызывающие модель, тратят средства аккаунта из вашего `.env`; сначала прочитайте `--help` и попробуйте `--dry-run`, если он есть.
