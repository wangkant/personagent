## Откройте его

Установите personagent из PyPI и откройте:

```sh
python -m pip install personagent
personagent
```

С [uv](https://docs.astral.sh/uv/) команда `uvx personagent` запускает его без отдельной установки.

Настройку может сделать агент для программирования: попросите его прочитать [setup-for-agents.md](setup-for-agents.md) и настроить personagent.

В Windows можно также скачать ZIP с исходным кодом, распаковать его и дважды щёлкнуть `start.bat`. Он создаст в папке собственное окружение Python и откроет ту же страницу.

Чтобы запустить его из клона, создайте для него отдельный venv: `python -m venv .venv`, затем `.venv/bin/python -m pip install -e .` и `.venv/bin/python -m persona_agent`. В Windows интерпретатор находится в `.venv\Scripts\python.exe`, либо можно дважды щёлкнуть `start.bat`.

## Добавьте ключ и общайтесь

Выберите сервис моделей, вставьте его API-ключ и нажмите **Проверить и начать чат**. Сначала выбраны бесплатные модели OpenRouter и персонаж «Чуткий слушатель». Ключ бесплатный, лимит — 50 запросов в день. В **Расширенные настройки** находятся название модели и адрес API, а в **Выбрать имя или характер** — имя и характер персонажа.

Ключ остаётся на вашем компьютере; чтобы проверить его, нажмите **Показать**. Сообщения чата идут в выбранный вами сервис моделей по обычным тарифам этого сервиса.

Ваш персонаж отвечает прямо на странице. Настройки сохраняются, поэтому при следующем запуске вы сразу попадёте в чат.

После настройки в разделе **Персонаж и настройки** появляется поле **Персона** с текстом, на котором основан персонаж. Перепишите, кто он и как говорит, затем нажмите **Сохранить персону**. Изменение применяется сразу, а то, чему персонаж научился, сохраняется.

Ниже в **Дополнительные функции** включаются веб-поиск, понимание изображений и возможность заговаривать первым. Поиск по умолчанию использует DuckDuckGo; с ключом Tavily он надёжнее. Пока вы не подключили приложение, в разделе **Чат** показывается короткая панель для начала работы.

## Подключите другие приложения

1. Нажмите **Подключить приложения** и выберите приложение. После подключения персонаж отвечает в групповых чатах и личных сообщениях этого приложения.
   - **Подключить по QR-коду**: QQ и личный WeChat. Нажмите **Получить QR-код** и подтвердите на телефоне.
     - QQ: отсканируйте мобильным QQ. QQ создаст бота или предложит выбрать уже имеющегося, а personagent получит его ключи. Если вы создали бота сами на [странице ботов QQ](https://q.qq.com/qqbot/openclaw/login.html), нажмите **Вставить значения вместо этого** и введите его AppID и AppSecret.
     - WeChat: отсканируйте в WeChat. Бот общается только один на один, потому что WeChat не передаёт таким ботам групповые сообщения.
   - **Вставить одно-два значения**: Telegram (токен от @BotFather), Discord (токен бота с включённым Message Content Intent), KOOK, Feishu, DingTalk, Slack, ИИ-бот WeCom, Mattermost и Misskey. Страница подскажет, какие значения скопировать из консоли приложения. Для всего остального используются значения по умолчанию.
   - **Дополнительно**: приложениям WeCom, официальным аккаунтам WeChat и вебхукам QQ нужен публичный адрес, перенаправляющий на их порт обратного вызова. OneBot v11 (NapCat) и Satori требуют другой программы, запущенной на этом компьютере.
2. personagent сам подключает QQ, WeChat, Telegram и Discord. Остальные приложения идут через AstrBot — сторонний мост. При первом подключении одного из них personagent скачивает AstrBot с отдельной средой Python 3.12, поэтому не закрывайте страницу, пока загрузка не закончится. Затем AstrBot работает в фоне, и входить ни в какую панель не нужно.
3. personagent проверяет учётные данные в приложении перед сохранением. Если приложение их отклоняет, страница сообщает об этом, и ничего не сохраняется.
4. Подключённые приложения перечислены вверху раздела **Подключить приложения**, где можно настроить их заново или отключить.

Чтобы найти бота QQ, откройте мобильный QQ и перейдите в «Контакты → Боты». Общайтесь с ним лично или добавьте в группу, которой вы владеете. Этот путь использует официальную платформу ботов QQ, поэтому не нужны ни личный аккаунт QQ, ни дополнительные программы. QQ решает, куда может попасть бот. Пока бот не сертифицирован, он может вступать только в группы, владельцем которых является его администратор, а настраивать песочницу не нужно. В группе он видит только сообщения с упоминанием через @, если только владелец группы не включит получение всех сообщений в профиле бота в этой группе. Сертификация и остальное, что касается аккаунта, описаны в [руководстве по ботам QQ](https://bot.q.qq.com/wiki/bot_new_product-intro/).

Если QR-код истёк, запросите новый. Если загрузка не удалась, повторите её, не проходя настройку модели заново. Подключение приложения открывает персонажу только группы и личные сообщения этого приложения; у других адаптеров списки разрешённых не меняются. LINE не предлагается, потому что AstrBot получает обратные вызовы LINE только через свою панель, а personagent её не запускает.

## В следующий раз

Откройте personagent снова. Настройки сохранены, а подключённые приложения возобновляют работу сами. Если он уже запущен, повторное открытие использует работающую страницу. Пока пользуетесь им, не закрывайте его окно запуска. Запущенные им процессы останавливаются вместе с ним, нажмёте ли вы **Выйти** или закроете окно, а то, что осталось после сбоя, останавливается при следующем запуске.

Когда на PyPI выходит новая версия, в разделе **Чат** появляется уведомление со ссылкой на примечания к выпуску и команду обновления для того способа, которым установлена эта копия. Копия, распакованная из ZIP с исходным кодом, вместо этого получает ссылку для загрузки нового кода со страницы выпусков. personagent обращается к pypi.org не чаще раза в день, и запрос содержит только номер его версии. Чтобы отключить проверку, задайте `UPDATE_CHECK_ENABLED=false` в `.env`.

Если вам удобнее командная строка, используйте `personagent start --terminal`, `personagent init --terminal`, `personagent up` или команды `chat`, `demo` (ключ не нужен), `run` и `connect`. Они сохраняют ваш `.env`, изменённую персону и усвоенные воспоминания. Другие платформы описаны в [полном руководстве](guide.md).
