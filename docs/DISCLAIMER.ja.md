## チャットプラットフォームとあなたのアカウント

personagent がチャットプラットフォームにつながる方法は 2 つあります。QQ 公式ボット、個人の WeChat、Telegram、Discord、Matrix、Twitch、IRC、Zulip、VK、Stoat の 10 個のプラットフォームには自分で接続します。それ以外のプラットフォームはサードパーティのブリッジを経由し、通常は personagent がダウンロードして動かす AstrBot を使います。リスクは、その接続が何としてログインするかで決まります。

- **公式ボット API** はボットのために作られています。QQ 公式ボット API、個人の WeChat 向けの Tencent iLink ボット API、Telegram と Discord のボット API、Zulip の Generic bot、コミュニティのアクセスキーを使う VK コミュニティの Bots Long Poll API、Stoat のボット、そして Slack、KOOK、Feishu/Lark、DingTalk、WeCom などのプラットフォームが該当します。それでも、各プラットフォームの開発者規約とレート制限には従う必要があります。
- **オープンなネットワーク上の専用アカウント。** Matrix、Twitch、IRC では、ボットはあなたがボットのために作成する普通のアカウントです。personagent はそのネットワークの文書化されたインターフェースを使います。Matrix ではボットのアカウントがあるホームサーバーの Matrix Client-Server API を使い、Twitch ではあなたが登録したアプリケーションに対してキャラクターのアカウントが承認したサインインで Twitch API を使い、IRC ではボット自身のニックネームで TLS 上の IRC プロトコルを使います。そのホームサーバー、Twitch、各 IRC ネットワークの規約が適用され、各ルームと各チャンネルのルールも適用されます。ボットが参加する前に許可を求めるところもあります。たとえば Libera.Chat では、AI ボットがチャンネルに参加する前に、そのチャンネルのオペレーターの明示的な許可が必要です。
- **非公式クライアント** は普通のユーザーアカウントとしてログインし、ソフトウェアで操作します。プラットフォームはこれを認めておらず、規約で禁じている場合もあります。アカウントの制限、凍結、永久停止につながることがあります。次のものが該当します。
  - **NapCat、LLOneBot、Lagrange などの OneBot 実装を使う QQ**。これは上級者向けの OneBot v11 オプションです。QQ 公式ボットにはどれも必要ありません。Tencent はこれらを認めておらず、クラウドや海外の IP アドレスからはリスクが最も高くなります。
  - **mautrix ブリッジ経由の WhatsApp、Signal、Messenger、Instagram、Google Messages など**。Matrix コネクターはこの方法でこれらにつながります。ブリッジは各ネットワークの非公式クライアントであり、自動メッセージについて規約で定めているネットワークもあります。[Matrix コネクターの注記](../integrations/matrix/README.ja.md#各ネットワークの規約)を参照してください。
  - そのほか、人としてログインするものすべて。

これらのいずれかを使うなら、失っても構わない専用アカウントを使い、メインのアカウントは絶対に使わないでください。可能であれば、クラウドサーバーではなく家庭のネットワークから動かしてください。つなぐすべてのネットワークの最新の規約を読んでください。アカウントの喪失や制限について、personagent の作者も、連携するサードパーティプロジェクト（AstrBot、NapCat、Koishi、mautrix など）のメンテナーも責任を負いません。

## ボットであることを伝える

- チャットの参加者に AI と話していることを伝え、追加する前にグループのオーナーか管理者の同意を得てください。そのことが明らかな名前をアカウントに付け、プラットフォームにプロフィールがあればそこにも書いてください。
- 誰かが本気で AI かどうか尋ねたら、personagent はそう答えるように作られています。これを否定させるようにペルソナを編集しないでください。
- 実在の人物になりすましたり、相手が誰と、何と話しているかについて人を欺いたりするために使わないでください。ボットの開示を義務づけたり、自動アカウントを制限したりしているプラットフォームや国があります。あなたに適用される規則を確認してください。
- 医療、法律、金融、危機に関するグループや子どもがいるグループなど、返信が人を傷つけたり誤らせたりするおそれのあるグループには入れないでください。
- 誰かに出ていくよう頼まれたり、自分について何を知っているのか尋ねられたりしたら、真剣に受け止めてください。管理者はメモを忘れさせることができ（`<name>, forget ...`）、保存しているものはすべてホームフォルダーにあります（下記参照）。

## モデルプロバイダーに見えるもの

返信のたびに、ペルソナ、チャットの最近のメッセージ（名前と時刻を含む）、これまでの会話の要約、ボットがそのチャットについて記憶している事実と出来事、学習した内容から取り出したものでできたプロンプトがモデルプロバイダーに送られます。記憶の整理では、1 つのチャットの最近のメッセージとメモが判定用モデルに送られます。ボット自身による学習の判断では、返信、それへのリアクション、提案された言い方が、その判断を行うモデルに送られます。ビジョンモデルを設定すると、画像はそこに送られます。オンにしたほかのサービスにも、この一部が見えます。設定したフォールバック、判定、自己評価、埋め込みのエンドポイントと、ウェブ検索が該当します。ウェブ検索は、キーがあれば Tavily に、なければ DuckDuckGo に短いクエリを送ります。更新確認が pypi.org に送るのは personagent のバージョン番号だけで、多くても 1 日 1 回です。`UPDATE_CHECK_ENABLED=false` でオフになります。

使う前に、各プロバイダーのデータ保持ポリシーを読んでください。プロンプトを保持するプロバイダーもあれば、オプトアウトしない限り学習に使うプロバイダーもあります。既定の OpenRouter の無料モデルは、そうしたプロバイダーに届くことがあります。ローカルモデル（Ollama、llama.cpp）ならプロンプトはあなたのマシンに留まります。チャットの参加者はどのプロバイダーの規約にも同意していないので、メッセージの行き先を伝えてください。

## あなたのマシンに保存するもの

保存するものはすべてホームフォルダーの下にあります。設定と API キーは `.env` にあります。ボットの認証情報と、代わりに動かす AstrBot は `platforms/` にあります。`runtime/` には、各チャットの最近のメッセージ（72 時間）、記憶している事実、出来事、要約、記憶から削除したもの（最大 30 日間）、判定したリアクション（原文のまま引用）、学習記録、学習した例、モデルの使用量の集計が入っています。`SERVER_LOG_FILE` を設定すると、ログにも会話の詳細が残ることがあります。フォルダーは非公開にしてください。絶対に公開したり Issue に添付したりせず、学習内容が大切ならバックアップしてください。他人のメッセージの保存と処理に関する法律は国によって異なり、自国の法律に従うのはあなたの責任です。

間違ったことを学ぶこともあります。リアクションによって変わるのは、同じチャットから一致した 2 つのリアクションがあり、少なくとも 1 つが返信の相手からのものである場合だけです。リアクションでは決まらない変更はボットがモデル呼び出しによって自ら判断しますが、モデルは判断を誤ることがあります。これらの変更について、誰かに確認を求めることはありません。すべての変更は、誰がなぜ決めたかとともに追記専用の学習記録に残り、`personagent learned` またはローカルページのアクティビティビューで取り消せます。ときどき確認してください。記憶している内容も、同じ場所または `personagent memory` で確認し、削除できます。
