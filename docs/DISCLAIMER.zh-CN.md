personagent 是以 [MIT 许可证](../LICENSE)发布的自由软件。它让一个 AI 角色出现在你的聊天里，而运行它的人是你。它说什么、在哪里说、使用哪些账号，都由你负责。本页列出一些容易被忽略的风险，不构成法律意见。

## 聊天平台和你的账号

personagent 接入聊天平台有两种方式。QQ 官方机器人、个人微信、Telegram 和 Discord 由它直接连接；其他平台通过第三方桥接程序接入，通常是 personagent 替你下载并运行的 AstrBot。风险大小取决于连接以什么身份登录。

- **官方机器人接口**本来就是为机器人设计的，包括 QQ 官方机器人接口、腾讯为个人微信提供的 iLink 机器人接口，以及 Telegram、Discord、Slack、KOOK、飞书、钉钉、企业微信等平台的接口。使用时仍须遵守各平台的开发者条款和频率限制。
- **非官方客户端**以普通用户账号登录，再由软件代为操作。平台不认可这种做法，条款中可能明令禁止，账号可能因此被限制、冻结乃至永久封禁。这类方式包括：
  - **通过 NapCat、LLOneBot、Lagrange 或其他 OneBot 实现接入 QQ**，即高级选项中的 OneBot v11。使用 QQ 官方机器人则完全不需要它们。腾讯不认可这些实现，从云服务器或境外 IP 登录时风险最高。
  - **通过 mautrix 桥接接入 WhatsApp、Signal、Messenger、Instagram、Google Messages 等**，即 Matrix 连接器的接入方式。桥接程序是这些网络的非官方客户端，其中一些网络的条款对自动发送消息有专门规定。详见 [Matrix 连接器的说明](../integrations/matrix/README.md#terms-of-each-network)（英文）。
  - 其他任何以真人账号登录的方式。

如果使用其中任何一种，请准备一个**专用的、丢失也无妨的小号**，不要用主号；条件允许时，在家庭网络中运行，不要部署在云服务器上。接入每个网络之前，请阅读它现行的条款。条款会变化，而承担后果的是你自己的账号。personagent 的作者，以及与它配合使用的第三方项目（AstrBot、NapCat、Koishi、mautrix 等）的维护者，均不对账号丢失或受限承担责任。

## 让大家知道这是机器人

- 告诉聊天中的人，他们正在与 AI 对话；把它加入群聊之前，先征得群主或管理员同意。给账号起一个一看便知是机器人的名字，平台支持个人简介的，也在简介中注明。
- 当有人认真地问它是不是 AI 时，personagent 的设计是如实回答。不要通过修改人设让它否认。
- 不要用它冒充真人，也不要让任何人误以为自己在和真人交谈。一些平台和国家要求标明机器人身份，或对自动化账号有所限制，请查明适用于你的规定。
- 不要把它放进回复可能造成伤害或误导的群，例如讨论医疗、法律、投资或心理危机的群，以及有未成年人的群。模型经常出错，而且语气笃定。
- 有人要求它离开，或询问它记录了自己的哪些信息时，请认真对待。管理员可以让它忘掉某条记录（`<名字> 忘掉 ...`），它保存的所有内容都在它的数据文件夹中（见下文）。

## 模型服务商能看到什么

每次回复时，模型服务商都会收到一段提示词，其中包括人设、聊天中最近的消息（含昵称）、机器人为这个聊天记下的笔记，以及它从已学内容中检索出的部分。如果配置了视觉模型，图片会发送给该模型。你启用的其他服务也会看到其中一部分，包括你配置的备用模型、评判模型、自评模型和向量模型，以及联网搜索。联网搜索会把一小段查询发送给 Tavily（填写了密钥时）或 DuckDuckGo。更新检查每天最多一次，只向 pypi.org 发送 personagent 的版本号；设置 `UPDATE_CHECK_ENABLED=false` 可以关闭。

使用前请阅读每家服务商的数据保留政策。有的服务商会保存提示词，有的会用于训练，除非你主动选择退出。本地模型（Ollama、llama.cpp）的提示词只留在你自己的电脑上。聊天中的其他人并未同意任何服务商的条款，请告诉他们消息会被发送到哪里。

## 它在你的电脑上存了什么

它保存的所有内容都在数据文件夹中。设置和 API Key 在 `.env` 里，机器人凭据和替你运行的 AstrBot 在 `platforms/` 里，`runtime/` 中则有聊天笔记、它判断过的反应（原文照录）、学习账本和学到的示例。如果设置了 `SERVER_LOG_FILE`，日志中也可能包含对话细节。请妥善保管这个文件夹，不要公开，也不要附在 issue 里；如果在意它学到的内容，请做好备份。各国关于存储和处理他人消息的法律不尽相同，遵守所在地的法律是你自己的责任。

它可能学错。一项改变需要同一个聊天中两次一致的反应，其中至少一次来自被回复的那个人。每项改变都记录在只追加的账本中，你可以用 `personagent learned` 或本地页面的「动态」查看和撤销。请定期检查。
