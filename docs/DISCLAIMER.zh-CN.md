## 聊天平台和你的账号

personagent 接入聊天平台有两种方式。QQ 官方机器人、个人微信、Telegram、Discord、Matrix、Twitch、IRC、Zulip、VK 和 Stoat 这十个平台由 personagent 直接连接；其他平台通过第三方桥接程序接入，通常是 personagent 代为下载并运行的 AstrBot。风险大小取决于连接以何种身份登录。

- **官方机器人接口**本身即为机器人而设计，包括 QQ 官方机器人接口、腾讯为个人微信提供的 iLink 机器人接口、Telegram 和 Discord 的机器人接口、Zulip 的通用机器人（Generic bot）、VK 社区的 Bots Long Poll API（使用社区访问密钥）、Stoat 的机器人，以及 Slack、KOOK、飞书、钉钉、企业微信等平台的接口。使用时仍须遵守各平台的开发者条款和频率限制。
- **开放网络上的独立账号。** 在 Matrix、Twitch 和 IRC 上，机器人是你为其单独创建的普通账号，personagent 使用该网络公开文档中的接口：在机器人账号所在的服务器上使用 Matrix Client-Server API；使用 Twitch API，并由角色的账号为你注册的开发者应用批准登录；使用基于 TLS 的 IRC 协议及机器人自己的昵称。该服务器、Twitch 和各 IRC 网络的条款均适用，各房间和频道的规则同样适用。部分网络要求机器人加入前须获得许可，例如 Libera.Chat 规定，AI 机器人加入频道前须获得该频道管理员的明确许可。
- **非官方客户端**以普通用户账号登录，再由软件代为操作。平台不认可这种做法，条款中可能明令禁止，账号可能因此被限制、冻结乃至永久封禁。这类方式包括：
  - **通过 NapCat、LLOneBot、Lagrange 或其他 OneBot 实现接入 QQ**，即高级选项中的 OneBot v11。使用 QQ 官方机器人则完全无需这些实现。腾讯不认可这些实现，从云服务器或境外 IP 登录时风险最高。
  - **通过 mautrix 桥接接入 WhatsApp、Signal、Messenger、Instagram、Google Messages 等**，即 Matrix 连接器的接入方式。桥接程序是这些网络的非官方客户端，其中一些网络的条款对自动发送消息有专门规定。详见 [Matrix 连接器的说明](../integrations/matrix/README.zh-CN.md#各网络的条款)。
  - 其他任何以真人账号登录的方式。

如果使用其中任何一种方式，请准备一个**专用的、即使丢失也无妨的小号**，切勿使用主号；条件允许时，请在家庭网络中运行，不要部署在云服务器上。接入每个网络之前，请阅读其现行条款。personagent 的作者，以及与其配合使用的第三方项目（AstrBot、NapCat、Koishi、mautrix 等）的维护者，均不对账号丢失或受限承担责任。

## 告知成员这是机器人

- 请告知聊天中的成员，他们正在与 AI 对话；将角色加入群聊之前，请先征得群主或管理员同意。请为账号设置一个可明确识别为机器人的名称；平台支持个人简介的，也请在简介中注明。
- 当有人认真询问角色是否为 AI 时，personagent 的设计是如实回答。请勿通过修改人设使其否认。
- 请勿用其冒充真人，也不要让任何人误以为自己在与真人交谈。一些平台和国家要求标明机器人身份，或对自动化账号有所限制，请查明适用于你的规定。
- 请勿将其加入回复可能造成伤害或误导的群聊，例如讨论医疗、法律、投资或心理危机的群聊，以及有未成年人的群聊。
- 有人要求角色离开，或询问角色记录了自己的哪些信息时，请认真对待。管理员可以让角色删除某条记录（`<名字> 忘掉 ...`），角色保存的所有内容都位于其数据文件夹中（见下文）。

## 模型服务商可见的内容

每次回复时，模型服务商都会收到一段提示词，其中包括人设、聊天中最近的消息（含昵称和时间）、此前对话的摘要、机器人记住的关于该聊天的事实和事件，以及从已学内容中检索出的部分。记忆整理会把一个聊天的近期消息和笔记发送给判断模型；机器人自行判断学习内容时，会把一条回复、对它的反应以及候选说法发送给作出判断的模型。如果配置了视觉模型，图片会发送给该模型。你启用的其他服务也会看到其中一部分，包括你配置的备用模型、评判模型、自评模型和向量模型，以及联网搜索。联网搜索会将一小段查询发送给 Tavily（填写了密钥时）或 DuckDuckGo。更新检查每天最多一次，只向 pypi.org 发送 personagent 的版本号；设置 `UPDATE_CHECK_ENABLED=false` 即可关闭。

使用前请阅读每家服务商的数据保留政策。有的服务商会保存提示词，有的会用于训练，除非你主动选择退出。默认的 OpenRouter 免费模型可能用到这类服务商。本地模型（Ollama、llama.cpp）的提示词只留在你自己的电脑上。聊天中的其他成员并未同意任何服务商的条款，请告知他们消息会被发送至何处。

## 本机保存的数据

personagent 保存的所有内容都位于数据文件夹中。设置和 API Key 位于 `.env` 中，机器人凭据和代为运行的 AstrBot 位于 `platforms/` 中，`runtime/` 中则保存各聊天最近 72 小时的消息、角色记住的事实、事件和摘要、最长 30 天内从记忆中移除的内容、角色判断过的反应（原文照录）、学习记录、学到的示例，以及模型用量的统计。如果设置了 `SERVER_LOG_FILE`，日志中也可能包含对话细节。请妥善保管该文件夹，切勿公开，也不要附在 issue 中；如果重视角色学到的内容，请做好备份。各国关于存储和处理他人消息的法律不尽相同，遵守所在地的法律是你自己的责任。

角色可能学到错误的内容。只有同一个聊天中出现两次一致的反应、且其中至少一次来自被回复的成员时，反应才会让改变生效。反应无法确定的改变由角色调用模型自行判断，而模型也可能判断失误。这些改变都无需他人确认。每项改变都记录在只追加的学习记录中，并注明由谁决定及其原因，你可以通过 `personagent learned` 或本地页面的「动态」撤销。请定期检查。角色记住的内容也可以在「动态」中或用 `personagent memory` 查看和删除。
